# literalsineos

A responsive retro-gaming launcher dashboard with original literalsineos branding and aqua/green arcade HUD accents inspired by the provided visual references.

## Run locally

Open `index.html` in a modern browser. The site is dependency-free and can also be served from this directory with any static file server.

## Published site

https://sinoesdawt.github.io/literalsineos/

The dashboard includes responsive navigation, quick-launch sections, a live greeting and date, and a web search/address bar. The Games page lets you save games in your browser, optionally add launch links, and attach a PNG, JPG, or WebP cover image. Cover images are resized and stored only in this browser; the static demo cannot publish uploads online. The Music page searches Apple's song catalog, filters explicit tracks and inappropriate metadata, and plays audio previews when available. Full-length listening is available through the audio-only Apple Music player and may require a subscription. Likes and playlists are saved in this browser. Pixel AI shows a typing indicator and uses offline intent rules and writing templates for common requests; it is not connected to ChatGPT or another generative AI service and cannot verify current facts. The Account page saves a player profile locally without passwords or online authentication. Settings include themes, layout controls, and a copyable Google Sites embed snippet; embedding requires a hosted HTTPS URL. The Friends and Chat pages store contacts and messages only in the current browser.
